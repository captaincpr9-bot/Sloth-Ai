How it opens

The app greets you with a landing hero — a meditating sloth animation — and one button: Open Sloth Workspace. No sign-up, no setup wizard. Scroll down and the tool is right there.

The Workspace

One box labelled “What is the messy thing?” — paste up to 30,000 characters, press Let the sloth handle it (or Ctrl + Enter). You never pick a task type; the local model classifies your paste itself.

🎙️ Too Lazy to Type — voice dictation 🤖 Model selector — pick any local Ollama model ✨ Zero Prompts badge

Sloth Persona — choose how the sloth talks back:

⚡ Ultra Lazy — minimum words, zero fluff 💼 Corporate — polished, professional 📋 Detailed — step-by-step breakdown 😌 Chill — friendly, relaxed

Need an example to test? One tap loads a sample:

✉️ Inbound Email 💬 Group Chat Thread 🧠 Chaotic Brain-Dump 🐛 Buggy Python Code

What you paste → what you get

✉️ An email / messageA ready-to-send reply draft
💬 A long text / chat threadA short summary + action items
🧠 A messy to-do listA clean, prioritised plan
🐛 Code with a bugA suggested fix, explained in one line

Every finished task tells you how many minutes you saved — and awards Sloth XP (10 XP per minute). The minutes are an honest rough estimate, not a measurement.

🦥 Baby Sloth · 0 XP 🛋️ Couch Sloth · 200 XP 🧘 Zen Sloth · 600 XP 👑 Legendary Sloth · 1,500 XP

🗄️ Lazy Vault

Every result is auto-saved to the Lazy Vault — a slide-over history drawer. Restore an old result, copy it, or delete it. It lives only in your browser's localStorage (offline), and one Clear Vault button wipes it all. No database, no server, no tracking.

How it works

1 · You pasteAnything messy. No task type to pick, no prompt to write.
2 · The sloth classifiesA local model reads your paste and works out what kind of thing it is — reply, summary, plan or fix.
3 · The work is doneIt runs the matching task, shows your time saved and XP, and files the result in the Vault.

100% local. No API keys. No accounts.

Sloth Mode runs entirely on your own laptop. The AI is Ollama running the open-weight Llama 3.2 model — your pasted text never leaves your machine. No external services, no sign-ups, nothing to pay for.

That's also why this page is just a showcase: the app itself lives on your computer, not on a server. The sloth would never make you upload your emails to the cloud — so there is no hosted demo to try here.

Run it yourself

You need Python 3.10+ and Ollama. Then:

ollama pull llama3.2:1b
git clone https://github.com/captaincpr9-bot/Sloth-Ai.git
cd Sloth-Ai
pip install -r requirements.txt
python app.py
# open http://localhost:5000

The default model is llama3.2:1b, so it even runs on a low-RAM machine. Got a stronger machine? Pull any Ollama model — it shows up in the app's model selector automatically.
